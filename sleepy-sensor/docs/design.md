# sleepy-sensor 设计文档

> 本文件是项目的设计「源头」,记录决策与理由,随版本演进。最后更新:2026-06。

## 1. 项目目标与约束

- ESP32-C3-WROOM-02 主控,**原生 USB**(IO18/19),console 走 USB Serial/JTAG → 腾出 IO20/21 做普通 GPIO,免 CP2102 漏电。
- 机械:**树莓派 Zero 兼容**。65×30mm,R3 圆角;M2.5 孔位 (3.5,3.5)(3.5,26.5)(61.5,3.5)(61.5,26.5)mm;40P 排针 pin1 x=8.37mm、2.54mm 间距、外排距上边 3.5mm。可套 Pi 外壳、插 Pi HAT。
- 用途:低功耗深睡温度计(SHT40)+ 开发板 + 接树莓派墨水屏 HAT(SSD1619,SPI)。
- 电池:单节锂电 **102540 / 1100mAh 裸电芯**(10×25×40mm,X-Y 可塞进板内且不挡四角孔,10mm 厚度偏厚)。
- 手焊为主(已把 0402/0603 换 0805);有加热台(可整板回流 QFN)。

## 2. v1(已打样)现状与修复

- **故障**:插 USB 反复重启(连接/断开声)。
- **根因**:LDO **HT7533 只有 100mA**,带不动 ESP32-C3 峰值 345mA。(当时也未装电池。)
- **修复**:U3 换 **HT7833(500mA,同 SOT-89 脚位)**。装上电池后可正常工作;**大概率不装电池也能 USB 烧录**(弱 LDO 才是重启真因,非缺电池)。
- **二次排查(2026-06)**:换 HT7833 后 3V3 正常但仍"无限重启"——串口显示 `invalid header: 0xffffffff`,**实为 Flash 空片无固件**,ROM bootloader 反复重试导致 USB 反复枚举,听感像重启。烧入固件后连续运行无复位,**v1 硬件验证通过**。教训:USB 连接/断开循环 ≠ 一定是电源问题,先抓串口 log 看 `rst:` 原因。
- **三次排查(2026-06)**:ESPHome 固件偶发 `E BOD: Brownout detector was triggered` 欠压循环(同板同电池,早上稳晚上崩,临界态)。**WiFi 满功率 TX 尖峰 ≈345mA 叠加 HT7833 压差,3V3 余量不足**。修复:`wifi: output_power: 8.5dB`(信号 -30dBm 余量巨大),60s 零复位。**v2 用 BQ24074+RT9080 后此问题应消失,但「降 TX 功率」值得保留为低功耗默认**。
- 固件:[firmware/sleepy-sensor.yaml](../firmware/sleepy-sensor.yaml)(ESPHome,电压上报 HA;面板在 HA 机器 Docker,首刷走本机 esptool,后续 OTA)。
- v1 充电芯片看丝印定充电电阻:**LTH7R/TP4054 → 1.8kΩ**;**TP4056 → 2.2kΩ**(0.5C≈550mA)。
- **v1 原理图核对(2026-06,SCH V1.0)**:充电芯片确认 **TP4056**;原理图 PROG 接 **R6=10k(≈120mA)**。**实板已确认 R6 被换成 1k(丝印 1001)**——排查「电流不足」重启时换的,本意提电流,但**充电电流限的是进电池的电流,治不了系统供电瓶颈(瓶颈在 LDO)**,属无效修复。1k → 设定 1.2A,**超 TP4056 自身 1A 上限**(手册 PROG 最小 1.2k),芯片热折返,且远超电脑 USB 口 500mA(亏电插电脑口 VBUS 会 UVLO 打嗝)。**待办:R6 换 2.2k(0.5C≈545mA);换前充电用墙充别用电脑口**。注:电池在位时 BAT+ 由电池稳压,此问题是隐患/加重项,不是 BOD 欠压主因(主因仍是 LDO 压差+TX 尖峰)。
- v1 电池 ADC 分压是 **R4/R5=1M/1M 常通**(漏电仅~2µA),**没有 MOS 门控**——门控分压是 v2 的设计,别混淆。ADC=IO4,换算 ×2。
- v1 欠压(BOD)主因修正:排除充电电流过载后,聚焦 **HT7833 压差 + 输出电容偏小(C4 仅 1µF)+ WiFi TX 尖峰 345mA**;治标=降 TX 功率 8.5dB(已验证 60s 零复位),治本=v2 的 BQ24074+RT9080+10µF。

## 3. v2 电源系统(定稿)

### 架构
```
USB-C ─→ BQ24074[IN]   [OUT] ─→ RT9080 LDO ─→ 3V3 ─→ ESP32-C3 / SHT40 / 墨水屏HAT
              [BAT]
               ↑
   DW01A + FS8205A 保护 ─ 裸电芯 102540 / 1100mAh
```

### BOM
| 模块 | 器件 | 立创编号 | 封装 | 焊接 |
|---|---|---|---|---|
| 充电 + 电源路径 | **BQ24074** | C54313 | QFN-16-EP 3×3 | 加热台回流 / 嘉立创代贴 |
| LDO 3V3 | **RT9080-33GJ5** | C841192 | SOT-23-5 | 手焊 |
| 裸电芯保护 | **DW01A + FS8205A** | (8205A≈C32254) | SOT-23-6 | 手焊 |
| 电量检测 | **2N7002 + 100k/100k** | C8545 | SOT-23 | 手焊(GPIO 控,无漏电) |
| BOOT 救砖 | 轻触按键 → IO9 | — | — | 手焊 |
| 电源指示 | LED + 1kΩ → **接 VBUS** | — | 0805 | 手焊(电池零漏电) |
| EN 复位 | SW1 + 1µF | — | — | 已有 |

### BQ24074 外围要点
- **IN** ← USB VBUS + 1µF
- **OUT** → RT9080 输入 + 10µF
- **BAT** → 保护后的电池 + 10µF
- **ISET** → **1.6kΩ** 到 GND(充电 ≈556mA = 1100mAh 的 0.5C)
- **散热焊盘 → GND**(打散热过孔)
- ⚠️ **待落地核手册**:ILIM(设 ~1A 支持边充边用)、TS(无 NTC 需接分压保持充电使能)、TMR、EN1/EN2 输入限流模式 —— 具体阻值画图时对 BQ24074 数据手册逐项确认,不凭记忆。

### 40P 排针 SPI 映射(墨水屏 HAT 直插)
对照微雪 e-Paper HAT,把信号映射到树莓派对应**物理脚位**:

| 物理脚 | 树莓派 | 接 ESP32-C3 |
|---|---|---|
| 11 | BCM17 / RST | IO20 |
| 18 | BCM24 / BUSY | IO21(输入) |
| 19 | BCM10 / MOSI | IO7 |
| 22 | BCM25 / DC | IO10 |
| 23 | BCM11 / SCLK | IO6 |
| 24 | BCM8 / CS | IO5 |
| 1/17 | 3V3 | 3V3 |

### GPIO 分配(原生 USB 腾出 IO20/21 后够用)
IO0/1=I2C(SHT40)、IO4=电池 ADC、IO3=分压 MOS 栅控、IO5/6/7/10/20/21=SPI(CS/SCLK/MOSI/DC/RST/BUSY)、IO9=BOOT、IO18/19=USB、IO2/IO8=空闲测试点。

## 4. 选型理由(为什么这么选)

- **BQ24074(电源路径)**:真 DPPM,OUT 是独立于电池的稳压系统输出 → 无电池/亏电也能即时启动、烧录;充电独立、终止准确;WiFi 峰值由电池补流不掉电;防 5V 灌电池。所有真 power-path 芯片都是 QFN/WSON(引脚多+散热盘),无易焊 SOP——这是行业事实。
- **RT9080 而非 ME6217**:RT9080 **Iq 2µA** vs ME6217 **100µA**。深睡温度计待机电流由 LDO 的 Iq 主导,2µA 比 100µA 续航强数倍。ME6217(800mA、180mV 压降、¥0.3)更适合常通电设备。
- **裸电芯必须保护**:充电器只在充电时防过充,不防过放/短路/过流。DW01A+FS8205A 最靠电芯那级。
- **charger-only 真相**(澄清):像喵哎/v1 那种「只充电、无路径」拓扑,**不装电池通常也能烧录/轻用**(充电 IC 在 CV 模式给系统供电),但**重载 WiFi 时无电池补峰值会不稳**,且电池利用率/充电终止不理想。power-path 是「更稳健 + 榨干电池」,不是「否则开不了机」。

## 5. v3 计划(分体,电源侧由 pisugar-clone 承担)

**决策(2026-06):自做「分体电源 HAT」取消,被 [pisugar-clone](../../pisugar-clone/) 替代**——电源/UPS 是独立项目,本项目只做主板:
- **无电池主板**:ESP32 + 原生 USB + 自带 RT9080 LDO + SHT40 + Pi 标准排针。全手焊无 QFN,独立可烧录。
- 排针供电随之定为 **5V**(PiSugar 形态即 5V 排针,主板 LDO 降压;原「5V vs 3V3」悬案就此拍掉)。
- 静态功耗:**低功耗对 v3 不是绝对需求**(2026-06 拍板)。pisugar-clone 按自己的目标做,深睡续航若受限可接受;真要极致低功耗再单独立项。

## 6. 经验教训

- **选型前必查数据手册关键参数**(电流/封装/Iq/压降)。HT7533 漏查电流能力(只 100mA)致整板重启报废。
- **别把结论说过头**。曾把 charger-only 说成「必须装电池才能开机」,被开源板实例纠正。区分「不能用」与「够用但不稳健」。
